A useful theme begins with a clear document structure. Decoration can wait; hierarchy cannot.

## A restrained foundation

The page should remain readable without scripts, external fonts, or special browser state.

- Semantic HTML carries the meaning.
- Components keep repeated template code in one place.
- Sass owns presentation, including the system colour preference.
